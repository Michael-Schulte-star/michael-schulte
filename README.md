# Michael Schulte Tour & Management Portal

Static responsive HTML/CSS/JavaScript prototype.

## Included
- Upcoming 2026 and 2027 event listings based on currently available public listings.
- Ticket inquiry flow.
- Fan membership levels: Fan, Premium, VIP, VVIP.
- Merchandise section.
- Live Meet & Greet request.
- Country selector excluding African countries as requested.
- Contact Management workflow.
- Telegram, Signal, IMO and Gmail contact details supplied by the client.
- Generated inquiry message and copy/send actions.

## Important before production
1. Replace illustrative membership/merchandise prices with the authorized management's final prices.
2. Confirm every event, venue, time, ticket category and inventory against the authorized ticketing/management system.
3. Add authorized WhatsApp and iMessage details if those channels are intended to be offered.
4. If the supplied contact accounts are not officially controlled by the authorized management, remove them.
5. For real ticket sales, connect the ticket button to the authorized ticketing provider or a secure backend/payment processor rather than treating this static page as a payment system.
6. Confirm rights for any artist photographs, logos, fonts and promotional assets used in production.

## Run locally
Open index.html in a browser, or serve the folder with a local HTTP server.
